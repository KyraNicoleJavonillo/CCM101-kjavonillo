## Mission Reflection

Among the three cloud platforms, Microsoft Azure impressed me the most because I liked how well it works with other Microsoft technologies. I found it interesting that Azure can be useful for organizations that already use Windows Server, Microsoft 365, and Active Directory. It showed me that choosing a cloud platform can depend on what a company is already using.

Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP) have many things in common. They all provide services for computing, storage, databases, networking, and other cloud needs. They also allow businesses to use cloud resources without having to manage all the physical hardware themselves.

Business requirements have a big effect on choosing a cloud platform. A company needs to consider its budget, existing technology, performance needs, number of users, and expected growth. For example, Microsoft Azure can be a good option for a company that already uses Microsoft products, while Google Cloud Platform (GCP) can be a good choice for organizations working with AI and machine learning.

Acting as a Cloud Solutions Consultant taught me that there is no single cloud platform that is best for every organization. I learned that I should first understand what the client needs and then compare the available cloud services before making a recommendation. This helped me think more about the business side of cloud computing.

After completing this mission, my GitHub Cloud Computing Portfolio became more complete and organized. I added information about Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP), along with comparison tables, recommendations, Linux investigation results, and screenshots. I also became more comfortable documenting my cloud computing activities using Markdown.
