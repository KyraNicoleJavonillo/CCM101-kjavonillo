## Microsoft Azure

### Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, databases, networking, security, artificial intelligence, and application development. It is also commonly used by organizations that already depend on Microsoft technologies.

### Global Infrastructure

Azure has a global infrastructure made up of **regions** and data centers located in different parts of the world. This allows organizations to choose locations for their applications based on performance, availability, and business requirements.

### Cloud Management Console

The Azure Portal is a web-based management tool used to create, configure, monitor, and manage Azure resources. Users can manage virtual machines, databases, storage, networking, and other services through the portal.

### Four (4) Core Services

| Service | Description |
|---|---|
| **Azure Virtual Machines** | Provides virtual computers for running applications and workloads. |
| **Azure Blob Storage** | Stores large amounts of unstructured data such as files and images. |
| **Azure SQL Database** | Provides a managed relational database service. |
| **Microsoft Entra ID** | Manages user identities and controls access to resources. |

### Three (3) Advantages

1. **Microsoft integration** – Azure works well with Microsoft products such as Windows Server and Microsoft 365.
2. **Scalability** – Resources can be adjusted based on the needs of an organization.
3. **Wide range of services** – Azure provides services for computing, storage, databases, networking, security, and AI.

### Typical Enterprise Use Cases

Organizations use Azure for hosting applications, migrating Windows servers, managing databases, supporting Microsoft 365 environments, and managing users and access through Microsoft identity services.
