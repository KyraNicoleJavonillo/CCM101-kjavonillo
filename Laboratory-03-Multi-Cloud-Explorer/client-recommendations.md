# Cloud Platform Recommendation Challenge

## Client A — Startup Company

Recommended Cloud Platform: **Amazon Web Services (AWS)**

I would recommend Amazon Web Services (AWS) because the startup has a limited budget but expects its application to grow. It provides scalable services, so the company can increase its resources as the number of users increases. It also has many services that can support a mobile application from development to deployment. The company could use Amazon EC2, Amazon S3, and Amazon RDS.

## Client B — University

Recommended Cloud Platform: **Microsoft Azure**

I would recommend Microsoft Azure because the university already uses Windows Server, Microsoft 365, and Active Directory. It has strong integration with Microsoft's existing technologies, which can make the migration process easier. The university can also manage users and access using Microsoft Entra ID. The university could use Azure Virtual Machines, Microsoft Entra ID, and Azure SQL Database.

## Client C — AI Research Company

Recommended Cloud Platform: **Google Cloud Platform**

I would recommend Google Cloud Platform because the company focuses on Artificial Intelligence and Machine Learning applications. It provides services and infrastructure that can support AI development and high-performance workloads. It also has strong support for Kubernetes, which can be useful when deploying applications. The company could use Compute Engine, Vertex AI, and Google Kubernetes Engine.

## Client D — Global E-Commerce Company

Recommended Cloud Platform: **Amazon Web Services (AWS)**

I would recommend Amazon Web Services (AWS) because the company needs reliable infrastructure that can serve customers around the world. It provides scalable services that can handle changes in traffic and support high availability. This is important for an e-commerce business because the number of customers can increase during busy periods. The company could use Amazon EC2, Amazon S3, and Amazon RDS.
