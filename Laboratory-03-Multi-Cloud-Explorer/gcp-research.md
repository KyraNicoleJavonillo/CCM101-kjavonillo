## Google Cloud Platform (GCP)

### Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is a cloud computing platform provided by Google. It offers services for computing, storage, databases, networking, artificial intelligence, machine learning, and application development.

### Global Infrastructure

Google Cloud has infrastructure located around the world and uses **regions** and **zones** to organize its resources. This allows businesses to deploy applications in different locations and improve their availability and performance.

### Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources. Users can create and monitor virtual machines, storage, databases, Kubernetes clusters, and other cloud services.

### Four (4) Core Services

| Service | Description |
|---|---|
| **Compute Engine** | Provides virtual machines for running applications and workloads. |
| **Cloud Storage** | Provides storage for files and other types of data. |
| **Cloud SQL** | Provides managed relational databases. |
| **Google Kubernetes Engine (GKE)** | Provides a managed environment for deploying and managing Kubernetes applications. |

### Three (3) Advantages

1. **Strong AI and machine learning capabilities** – Google Cloud provides several services and tools for developing AI and ML applications.
2. **Kubernetes support** – GKE makes it easier to deploy and manage applications using Kubernetes.
3. **Global infrastructure** – Google Cloud provides infrastructure in different regions around the world.

### Typical Enterprise Use Cases

Businesses use Google Cloud for artificial intelligence, machine learning, data analytics, application hosting, database management, and Kubernetes-based applications.
