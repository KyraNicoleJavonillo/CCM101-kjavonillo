## Amazon Web Services (AWS)

### Brief Overview

Amazon Web Services (AWS) is a cloud computing platform developed by Amazon. It provides different services such as computing, storage, databases, networking, and security that businesses can use without having to maintain all of their own physical infrastructure.

### Global Infrastructure

AWS has a global infrastructure made up of **Regions** and **Availability Zones**. These locations allow businesses to deploy their applications in different parts of the world while improving availability, performance, and reliability.

### Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Through the console, users can create and configure resources such as virtual machines, databases, storage, and networking services.

### Four (4) Core Services

| Service | Description |
|---|---|
| **Amazon EC2** | Provides virtual servers that can be used to run applications and workloads. |
| **Amazon S3** | Provides object storage for files, documents, images, and other data. |
| **Amazon RDS** | Provides managed relational databases without requiring users to manage the database infrastructure themselves. |
| **AWS IAM** | Controls user access and permissions for AWS resources. |

### Three (3) Advantages

1. **Scalability** – AWS allows businesses to increase or decrease their resources depending on their workload.
2. **Wide range of services** – It provides many services for computing, storage, databases, networking, security, and other cloud needs.
3. **Global availability** – Its global infrastructure allows applications and services to be deployed in different locations around the world.

### Typical Enterprise Use Cases

Businesses commonly use AWS to host websites and applications, store large amounts of data, manage databases, create backup systems, and support applications that need to scale as the number of users increases.
