# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory helped me get familiar with Linux and the basic tools used in cloud computing. I also started building my Cloud Computing portfolio on GitHub.

## Objectives

* Learn the basics of a Linux environment
* Practice using Linux commands
* Check basic system information
* Manage files and folders
* Create and organize a GitHub repository
* Document my laboratory work

## Activities Performed

I used the KillerCoda Playground to practice Linux commands and explore the Linux environment. I also checked the system information, created files and folders, and set up my Cloud Computing portfolio on GitHub.

## Skills Learned

I learned how to navigate and work in Linux, use basic commands, manage files and folders, and organize my work using GitHub and Markdown.
